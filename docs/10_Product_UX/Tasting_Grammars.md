# Grammaires de dégustation par type de vin

> **Principe** : la couleur du vin est une hypothèse utilisateur, jamais une vérité.
> Le formulaire suit l'hypothèse, pas la réalité. On ne corrige jamais.
>
> Ce document définit les grammaires sensorielles — pas l'interface.
> La correspondance avec le code est donnée en fin de document.

---

## Pourquoi des grammaires distinctes

Un formulaire générique avec hide/show échoue pour une raison simple :
il force une grille d'attention uniforme sur des expériences fondamentalement différentes.

La dégustation d'un rouge est **tactile** : on cherche la texture des tanins, leur grain, leur fondu.
La dégustation d'un blanc est **structurale** : on cherche la ligne de tension entre acidité et gras.
La dégustation d'un pétillant est **cinétique** : on observe le comportement des bulles dans le temps.
La dégustation d'un orange est **déroutante** : on cherche à comprendre ce qu'on ressent d'inhabituel.

Chaque grammaire est une séquence d'attention différente.

## Rouge

### Logique de dégustation

Le rouge se perçoit d'abord visuellement (intensité, évolution), puis tactilement en bouche.
Les tanins sont **le** repère central. Tout le reste s'organise autour d'eux.
La maturité du fruit et les notes tertiaires donnent l'âge et l'origine.

**Séquence d'attention :**
1. Couleur → intensité + évolution (rubis vif = jeune, tuilé = âgé)
2. Nez → fruité : type de fruit + fraîcheur (primaire) vs complexité (tertiaire)
3. Bouche → tanins en premier : grain, texture, fondu
4. Corps et alcool
5. Acidité (souvent perçue en arrière-plan pour les rouges)
6. Longueur et persistance

### Axes centraux

| Axe | Pourquoi central |
|---|---|
| **Tanins** | Trait définissant du rouge — texture, fondu, astringence |
| **Maturité du fruit** | Révèle millésime, origine, style de vinification |
| **Corps** | Volume en bouche, densité |
| **Notes tertiaires** | Évolution — sous-bois, cuir, tabac, truffe |
| **Longueur** | Mesure de l'intérêt |

### Axes secondaires

- Acidité (présente mais rarement premier repère)
- Intensité aromatique (perçue mais moins discriminante qu'en blanc)
- Boisé (si présent : vanille, café, grillé)

### Inutile pour un rouge

- Effervescence, bulles
- Gras/Onctuosité (vocabulaire blanc)
- Minéralité (très marginale, non discriminante)
- Dosage

### Vocabulaire naturel

**Tanins** : veloutés, soyeux, granuleux, poudre de cacao, anguleux, astringents, fondus, présents, discrets, rugueux

**Maturité** : fruit frais / fruit cuit / fruit confit / surmaturité / raisin sec

**Fruité** : cassis, mûre, myrtille, cerise noire, cerise griotte, fraise des bois, prune, grenade

**Corps** : mince, léger, moyen, charnu, imposant, dense

**Tertiaire** : sous-bois, humus, cuir, tabac, truffe, champignon, réglisse, olive noire, garrigue

### Champs — ordre logique

1. Robe (chips) : Rubis clair · Rubis · Grenat · Pourpre · Tuilé · Brun
2. Intensité aromatique (slider)
3. Famille aromatique (chips multi) : Fruits noirs · Fruits rouges · Floral · Épices · Terreux · Animal · Végétal · Boisé · Balsamique
4. Notes libres nez (texte)
5. **Tanins** — axe principal (chips 5 niveaux) : Quasi absents · Discrets · Présents · Marqués · Très marqués
   → Texture tanin (chips) : Veloutés · Soyeux · Granuleux · Anguleux · Poudre de cacao
6. **Maturité** (chips) : Fruit frais · Fruit mûr · Fruit cuit/confit · Tertiaire dominant
7. Corps (chips 3) : Léger · Moyen · Ample
8. Acidité (chips 3, secondaire) : Fraîche · Souple · Plate
9. Longueur (chips 3) : Courte · Moyenne · Longue
10. Notes libres bouche (texte)

## Blanc

### Logique de dégustation

Le blanc se perçoit d'abord par la **tension** — l'opposition entre fraîcheur acide et richesse texturale.
C'est un équilibre dynamique. Un blanc plat = trop de gras, trop peu d'acidité.
Un blanc tranchant = acidité sans corps.

La minéralité est souvent le marqueur d'origine le plus révélateur.
Le boisé peut masquer ou accompagner — à identifier.

**Séquence d'attention :**
1. Couleur → pâle = jeune/nord, doré/ambré = âgé/sud/boisé
2. Nez → aromate dominant (fruité, floral, minéral, végétal) + fraîcheur vs richesse
3. Bouche → acidité d'abord, puis gras, puis minéralité
4. Texture (fluide, huileuse, dense)
5. Finale (amère, minérale, fraîche, chaude)

### Axes centraux

| Axe | Pourquoi central |
|---|---|
| **Acidité** | Le repère structurant principal du blanc |
| **Gras / Texture** | Contrepoint à l'acidité — richesse perçue |
| **Minéralité** | Marqueur d'origine très fort pour certains blancs |
| **Fruité** | Type (agrumes = fraîcheur, fruits à chair blanche = maturité, fruits tropicaux = chaleur) |
| **Boisé** | Signature de vinification (oxydatif vs réducteur) |

### Axes secondaires

- Corps (souvent déduit de texture + acidité)
- Longueur
- Sucrosité perçue (demi-sec, moelleux : si évident à noter)

### Inutile pour un blanc

- Tanins (sauf rares exceptions naturelles — hors-scope pour un aveugle)
- Astringence
- Notes tertiaires animales
- Effervescence

### Vocabulaire naturel

**Acidité** : tranchante, vive, tendue, nerveuse, fraîche, souple, ronde, fondue, plate, molle

**Texture** : fluide, légère, sèche, soyeuse, onctueuse, grasse, huileuse, dense, épaisse

**Minéralité** : caillou, silex, craie, pierre à fusil, iode, salin, fumé, ardoise

**Fruité** : citron vert, pamplemousse, citron, bergamote, pomme verte, poire, pêche blanche, abricot, ananas, fruit de la passion, mangue, melon

**Boisé/Oxydatif** : vanille, beurre, crème, brioche, noisette, amande grillée, toast

### Champs — ordre logique

1. Robe (chips) : Jaune pâle · Jaune citrin · Jaune doré · Or · Ambré
2. Intensité aromatique (slider)
3. Famille aromatique (chips multi) : Agrumes · Fruits à chair blanche · Fruits tropicaux · Floral · Minéral · Végétal · Miel/Cire · Boisé · Oxydatif
4. Notes libres nez (texte)
5. **Acidité** — axe principal (chips 5) : Plate · Souple · Fraîche · Vive · Tranchante
6. **Texture / Gras** (chips 4) : Légère et sèche · Souple · Onctueuse · Grasse et ronde
7. **Minéralité** (chips) : Absente · Discrète · Présente · Marquée
   → Type (chips, si présente) : Craie · Silex · Iode · Fumé · Pierre mouillée
8. **Boisé** (chips) : Absent · Discret · Présent · Dominant
9. Longueur (chips 3)
10. Notes libres bouche (texte)

## Rosé

### Logique de dégustation

Le rosé est fréquemment sous-estimé comme exercice de dégustation.
Son spectre est en réalité très large : du rosé provençal ultra-pâle et minéral
au Tavel structuré, proche d'un rouge léger.

La question centrale : **est-ce un rosé de fraîcheur ou un rosé de structure ?**

La sucrosité perçue est plus critique qu'en rouge ou blanc car beaucoup de rosés
semblent demi-secs sans l'être techniquement — l'aromatique fruité induit en erreur.

**Séquence d'attention :**
1. Couleur → intensité (révèle méthode et style)
2. Nez → type de fruité (rouge léger ou blanc ?)
3. Bouche → fraîcheur d'abord, puis corps, puis légère structure si présente
4. Sucrosité perçue (sec ? légèrement sucré ?)
5. Finale (nette, légèrement amère = signe de qualité)

### Axes centraux

| Axe | Pourquoi central |
|---|---|
| **Fraîcheur / Vivacité** | Le critère N°1 d'un rosé réussi |
| **Type de fruité** | Distingue styles et origines |
| **Sucrosité perçue** | Souvent trompeuse, à identifier |
| **Corps** | Distingue rosé pâle vs rosé charnu |
| **Légère structure** | Présence tannique résiduelle (Tavel, Bandol) |

### Axes secondaires

- Longueur
- Finale (amertume légère = signe positif)

### Inutile pour un rosé

- Tanins développés (s'il y en a, c'est une structure légère seulement)
- Minéralité complexe
- Notes tertiaires
- Boisé (très rare)

### Vocabulaire naturel

**Fraîcheur** : vif, frais, croquant, désaltérant, friand, tendu

**Fruité** : fraise, framboise, pastèque, groseille, pêche, pamplemousse rose, cerise, cassis délicat, fleur de rose

**Corps** : coulant, léger, souple, charnu, généreux

**Finale** : nette, légèrement amère, courte, fraîche, persistante

### Champs — ordre logique

1. Robe (chips) : Rose pâle · Rose saumon · Rose framboise · Rose foncé · Orangé
2. Intensité aromatique (slider)
3. Famille aromatique (chips multi) : Fruits rouges légers · Fruits blancs · Floral · Agrumes · Bonbon/Confiture
4. Notes libres nez (texte)
5. **Vivacité** (chips 4) : Plate · Souple · Fraîche · Très vive
6. **Corps** (chips 3) : Léger et coulant · Souple · Charnu
7. **Sucrosité perçue** (chips 4) : Sec · Légèrement sucré · Demi-sec · Sucré
8. **Structure** — si perçue (chips, optionnel) : Pas de structure · Légère présence · Structure nette
9. Longueur (chips 3)
10. Notes libres bouche (texte)

## Pétillant / Effervescent

### Logique de dégustation

L'effervescence change tout. Les bulles ne sont pas un décor — elles sont un ingrédient.
Elles portent les arômes différemment, elles modifient la perception de l'acidité,
elles créent une texture cinétique unique.

La question centrale est double :
**Quelle est la qualité de la mousse ?** (finesse, persistance, intégration)
**Quel est le niveau de dosage ?** (de brut nature à doux — souvent impossible à deviner à l'aveugle, mais l'exercice est pertinent)

Les arômes de maturité (beurré, brioche, levure) signalent la méthode et l'âge.

**Séquence d'attention :**
1. Couleur + Mousse : aspect, densité, cordon de bulles
2. Nez → vivacité ou maturité ? Levure, brioche, ou fruit frais ?
3. Bouche → bulles d'abord : texture, finesse, agressivité
4. Dosage perçu (sec, légèrement sucré ?)
5. Corps résiduel sous les bulles
6. Finale (fraîche, crémeuse, minérale)

### Axes centraux

| Axe | Pourquoi central |
|---|---|
| **Effervescence** | La texture des bulles est LE critère discriminant |
| **Dosage perçu** | Sec vs sucré — très variable, souvent surprenant |
| **Maturité** | Fruit frais vs brioche/levure = méthode et âge |
| **Vivacité** | Tension acide perçue à travers les bulles |
| **Finale** | Persistance de la mousse + longueur aromatique |

### Axes secondaires

- Corps sous-jacent (difficile à évaluer mais présent)
- Type de fruité (agrumes = jeune/nord, fruits tropicaux = chaud/mature)

### Inutile pour un pétillant

- Tanins
- Minéralité complexe (sauf Champagne avec craie — marginal)
- Gras / Texture huileuse
- Notes tertiaires animales

### Vocabulaire naturel

**Bulles** : fines, crémeuses, fondantes, vives, agressives, grossières, persistantes, disparaissant vite

**Mousse** : généreuse, légère, soyeuse, vaporeuse, épaisse, courte

**Maturité** : levure fraîche, brioche, beurre, noisette, grillé, pain de mie, craie

**Fruité** : citron, poire, pomme verte, pamplemousse, agrumes confits, ananas (si mature), fraise (si rosé)

**Dosage** : très sec, sec, légèrement sucré, doux

### Champs — ordre logique

1. Robe + Mousse (chips combinés) : Blanc cristallin / Jaune pâle / Rosé pâle / Doré · Mousse abondante / Mousse légère / Peu de mousse
2. **Bulles — qualité** (chips 5) : Très fines et persistantes · Fines · Moyennes · Vives et piquantes · Grossières
3. Intensité aromatique (slider)
4. **Registre aromatique** (chips) : Fruit frais dominant · Levure/Brioche · Fruité mûr · Oxydatif · Mixte
5. Famille aromatique détail (chips multi) : Citron · Poire · Pomme · Pamplemousse · Ananas · Fraise · Brioche · Levure · Beurre · Noisette · Amande · Toast
6. **Dosage perçu** (chips 5) : Brut nature · Brut · Légèrement sucré · Demi-sec · Doux
7. **Vivacité** (chips 4) : Plate · Souple · Fraîche · Tendue
8. Corps sous-jacent (chips 3) : Léger · Moyen · Charnu
9. Finale (chips 2) : Fraîche et nette · Crémeuse et longue
10. Notes libres (texte)

## Orange (macération pelliculaire)

### Logique de dégustation

L'orange est le type le plus déroutant à l'aveugle — et le plus révélateur.
C'est un vin blanc qui a subi une macération sur peaux, acquérant une structure
et des amers habituellement réservés aux rouges, dans un registre aromatique
spécifique (sec, confit, oxydatif intentionnel).

La question centrale n'est pas "est-il bon ?" mais **"est-ce intentionnel ou déviant ?"**
L'oxydation d'un orange peut être une signature ou un défaut selon le style.

La texture phénolique est **fondamentalement différente** des tanins rouges :
c'est un grippage de type peau d'orange ou thé, pas un serrement de bouche.

**Séquence d'attention :**
1. Couleur → ambré, cuivré, orangé : plus la couleur est intense, plus la macération est longue
2. Nez → étrangeté assumée : abricot sec, coing, noix, thé, oxydatif ou non ?
3. Bouche → phénolique d'abord : texture, grippage
4. Amers : type (noix, orange amère, thé noir)
5. Acidité résiduelle (souvent atténuée par la macération)
6. Longueur (souvent longue via les phénols)

### Axes centraux

| Axe | Pourquoi central |
|---|---|
| **Texture phénolique** | Trait définissant — grippage doux, tanins de peau |
| **Amers** | Type et intensité — noix, zeste, thé noir, peau d'orange |
| **Registre oxydatif** | Intentionnel ou signe de fragilité ? Noix, pomme au four, curry |
| **Fruité atypique** | Abricot sec, coing, mandarine confite, figue — jamais frais |
| **Acidité résiduelle** | Présente ou absente — dépend de la durée de macération |

### Axes secondaires

- Longueur (souvent longue, portée par les phénols)
- Corps (souvent dense/généreux)

### Inutile pour un orange

- Effervescence
- Fraîcheur aromatique (incompatible avec le profil)
- Minéralité (non pertinente ici)
- Vocabulaire standard des blancs (pomme verte, citron = absent)

### Vocabulaire naturel

**Texture** : grippage doux, enrobant, phénolique, ferme, tanin de peau, tanin de thé, peau d'orange

**Amers** : noix fraîche, noix de cajou, thé noir, orange amère, zeste, amande sèche, artichaut

**Oxydatif** : noix, pomme au four, cire, miso, curry doux, rancio léger, pomme séchée

**Fruité** : abricot sec, coing, mandarine confite, figue sèche, mangue mûre, datte, safran

**Acidité** : absente · discrète · encore présente · vive (rare)

### Champs — ordre logique

1. Robe (chips) : Jaune ambré · Or cuivré · Tuilé orangé · Ocre · Brun orangé
2. Intensité aromatique (slider)
3. **Registre oxydatif** (chips) : Absent · Discret · Présent · Dominant
4. Famille aromatique (chips multi) : Abricot sec · Coing · Figue · Mandarine confite · Noix · Thé · Épices douces · Miso/Fermenté · Fleurs séchées
5. Notes libres nez (texte)
6. **Texture phénolique** — axe principal (chips 5) : Absente · Discrète · Présente · Marquée · Très marquée
   → Type (chips) : Peau d'orange · Thé noir · Tanin sec · Enrobant
7. **Amers** (chips) : Absents · Fins · Présents · Intenses
   → Type (chips si présents) : Noix · Zeste d'agrume · Thé · Amande sèche
8. **Acidité résiduelle** (chips 4) : Absente · Discrète · Perceptible · Encore vive
9. Corps (chips 3) : Léger · Dense · Très généreux
10. Longueur (chips 3)
11. Notes libres bouche (texte)

## Clairet

### Logique de dégustation

Le clairet est souvent mal compris parce qu'on l'aborde soit comme un rosé épais,
soit comme un rouge léger. Ce n'est ni l'un ni l'autre.

C'est un vin de **transition et de fraîcheur avec de la mâche** :
plus de corps qu'un rosé, beaucoup moins de structure qu'un rouge.
Le fruité rouge doit rester vif, pas cuit.

La question centrale : **est-ce que ça tient ? La fraîcheur est-elle préservée malgré la structure légère ?**

**Séquence d'attention :**
1. Couleur → rose foncé à rouge rosé très pâle (discriminant)
2. Nez → fruité rouge vif (cerise, groseille, cassis léger)
3. Bouche → fraîcheur d'abord, puis légère présence tannique
4. Corps : moyen, entre rosé et rouge léger
5. Finale : nette, légèrement tannique, courte à moyenne

### Axes centraux

| Axe | Pourquoi central |
|---|---|
| **Fruité rouge vif** | Ce qui distingue un clairet d'un rosé foncé |
| **Fraîcheur** | Doit être maintenue malgré la structure |
| **Structure légère** | Légère présence tannique — ni rosé ni rouge |
| **Corps** | Entre les deux mondes |

### Axes secondaires

- Longueur
- Acidité (souvent fraîche)

### Inutile pour un clairet

- Tanins développés (incompatible)
- Notes tertiaires (vin de fruit frais)
- Minéralité
- Oxydation

### Vocabulaire naturel

**Fruité** : cerise fraîche, groseille, framboise, cassis délicat, grenadine, hibiscus

**Texture** : coulant, léger, avec mâche, souple, fruité

**Structure** : légère présence, ferme mais frais, tannique sans lourdeur

### Champs — ordre logique

1. Robe (chips) : Rose foncé · Rouge rosé · Grenat très pâle
2. Intensité aromatique (slider)
3. Famille aromatique (chips multi) : Cerise · Groseille · Framboise · Cassis léger · Floral rouge · Épices légères
4. Notes libres nez (texte)
5. **Fraîcheur** (chips 4) : Plate · Souple · Fraîche · Vive
6. **Structure légère** (chips 4) : Aucune · Légère présence · Présente · Nette
7. Corps (chips 3) : Léger · Moyen · Charnu
8. Longueur (chips 3)
9. Notes libres bouche (texte)

## Autre

### Logique de dégustation

Cette catégorie couvre des vins structurellement différents des six précédents :
vins fortifiés (Porto, Madère, Banyuls), oxydatifs (Xérès, Vin Jaune),
moelleux et liquoreux (Sauternes, Jurançon), naturels non catégorisables.

Ce n'est pas un formulaire générique — c'est un formulaire **déclaratif**.
L'utilisateur commence par nommer ce qu'il perçoit, pas par remplir des cases.

**Le champ le plus important est le premier : "Ce que tu perçois d'emblée"** (texte libre).

### Axes — selon sous-type perçu

**Si liquoreux / moelleux :**
- Sucrosité (très présente, à caractériser : miel, rôti, botrytis, surmaturation)
- Texture (onctuosité, viscosité)
- Acidité (contrepoint indispensable : présente ou non ?)
- Fruité concentré (abricot, coing, miel, marmelade, pourriture noble)

**Si fortifié :**
- Alcool perçu (chaleur, caractère eau-de-vie)
- Sucrosité (sec = Fino, doux = Tawny, Porto)
- Oxydation (noix, rancio, curry, cire)
- Longueur et persistance (souvent très longue)

**Si oxydatif (Xérès, Vin Jaune) :**
- Registre oxydatif dominant (noix, curry, pomme au four, rancio)
- Salinité (aldéhyde acétique — présent dans les Fino)
- Corps et texture sous l'oxydation
- Finale (noix persistante ?)

### Champs — ordre logique

1. **"Ce que tu perçois d'emblée"** (texte libre — obligatoire)
2. Robe (texte libre)
3. **Sous-type perçu** (chips, aide à l'orientation) : Liquoreux · Fortifié · Oxydatif · Naturel non catégorisable · Je ne sais pas encore
4. Intensité aromatique (slider)
5. Famille aromatique (chips multi, large) : Miel · Rôti/Botrytis · Noix · Curry · Abricot sec · Figues · Alcool marqué · Oxydatif · Épices · Levure · Autre
6. **Sucrosité** (chips 5) : Sec · Légèrement sucré · Demi-sec · Moelleux · Liquoreux
7. **Alcool perçu** (chips 3) : Discret · Présent · Chaleureux
8. **Oxydation** (chips 4) : Absente · Légère · Présente · Dominante
9. **Texture** (texte libre)
10. Longueur (chips 3)
11. Notes libres bouche (texte)

## Mutualisation intelligente

### Ce qui est réellement commun (toujours mutualisable)

| Brique | Raison |
|---|---|
| **Intensité aromatique** (slider) | Universelle — toujours pertinente, même question |
| **Longueur / Persistance** (chips 3) | Universelle |
| **Notes libres nez** (texte) | Universelle |
| **Notes libres bouche** (texte) | Universelle |
| **Bloc Style** (note, coup de cœur, accords, impression) | Universelle — section finale identique pour tous |

### Ce qui est mutualisable avec des options différentes

| Brique | Ce qui change par type |
|---|---|
| **`<RobeChips>`** | Couleurs différentes selon le type (rubis vs jaune pâle vs ambré vs rose) |
| **`<AromeFamiliesChips>`** | Options différentes — les familles aromatiques d'un rouge ≠ celles d'un orange |
| **Acidité** | Même composant, label différent : "Acidité" (blanc), "Vivacité" (rosé/pétillant), "Fraîcheur" (rouge) |
| **Corps** | Même composant, pertinence variable (fort pour rouge/blanc, secondaire pour pétillant) |

### Ce qui ne doit JAMAIS être mutualisé

| Brique | Raison |
|---|---|
| **Tanins** (rouge) ↔ **Texture phénolique** (orange) | Même sensation superficielle, expérience radicalement différente. Le confondre = perdre la nuance |
| **Effervescence + Bulles** (pétillant) | Spécifique, sans équivalent dans les autres types |
| **Dosage perçu** (pétillant) | N'a de sens que pour l'effervescent |
| **Amers phénoliques** (orange) | Non pertinents ailleurs |
| **Registre oxydatif déclaratif** (orange / autre) | Dans les autres types, l'oxydation est un défaut — ici c'est une signature |
